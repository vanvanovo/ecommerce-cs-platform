## 四、设计要点

1. **路由 / 执行 / 汇总三层解耦**：Qwen 路由（本地毫秒级）→ Orchestrator 执行（三层兜底 + HitL 标准化）→ 汇总校验；
2. **短路直出**：单意图高置信跳过汇总（`meta.mode` 标记 `short_circuit`，P6 实测省时数据）——避免“为汇总而汇总”；
3. **一致性校验是确定性的**：汇总文本里出现的订单号/金额必须能在专项结果里找到，找不到就**降级为原文拼接**（不润色），从机制上防“汇总幻觉”；
4. **低置信自动转人工**（<0.6）+ “转人工”短语零 Token 直达；
5. **`Orchestrator.handle` 真正接入 HTTP**：此前只是离线模块——现在降级返回、HitL 暂停、多 Agent 都被标准化成 `AgentResponse`，HTTP 主链路统一走它（工程补齐点）。
