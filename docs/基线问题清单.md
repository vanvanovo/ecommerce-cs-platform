## 三、环境与运行观察

- **内存紧张** ⚠️：总 15.9GB，全量运行（Docker 四件套 + 后端三模型 + 前端）后**可用仅 ~0.5GB**。P1 起涉及"本地 Qwen 路由 + BGE-M3 + Reranker"同机运行时，需按方案 §四的显存/内存策略执行（路由器考虑 CPU/按需加载）。
- **模型延迟**：`deepseek-v4-flash` 为推理模型，首次路由+生成 15.5s，后续 6~7.6s；本地模型 CPU 加载约 10s（三次合计）。
- **GPU 未启用**：torch 2.5.1+cpu；按计划 P6 换 cu124 版（3060 6GB，注意与 Ollama 路由模型争显存）。
- **端口**：后端 8000、前端 3000、Postgres 5433、Milvus 19531；另有既有容器 `milvus_standalone`(19530) / `mysql8`(3307) 不冲突。
- **旧数据卷保留**：`eduagent_pro_*`（上次课程运行的数据），未删除；本期使用 `cs-platform_*` 新卷。
