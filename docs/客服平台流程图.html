图 3 · 关键子流程：退款审批 HitL（时序图）

复刻 EduAgent 试卷批改的 interrupt / resume 全链路：冻结图 → 主管审批 → 恢复执行 → 创建工单。

    U->>API: “耳机拆封想退，订单 A1024”

    M-->>G: 订单信息 + 可退判定
    G->>G: 金额 699 > 阈值 500 → 需审批
    G-->>API: interrupt（待审批材料）
    API-->>S: 工单出现在“待审批”列表
    S->>API: POST /aftersale/{id}/confirm（approve/modify）
    API->>G: Command(resume=decision)
    G->>M: create_return_ticket(A1024)
    M-->>G: 工单号 RT-2026-xxxx
    G-->>U: 退货方案 + 退款时效（SSE 流式）
